APP NAME: THUMBLAB

Build a comprehensive, single-page web app using HTML5.

Core Stack: Tailwind CSS (CDN), Puter.js (AI), Fabric.js (Canvas Editor), Dexie.js (Template Storage), and JSZip (for Bulk Export).

The Architecture:
Three-Tab Sidebar:
Tab 1: AI Generator: Input for Video Script or Instructions or Thumbnail Strategy Note (NexLev MCP), Model Toggle (Flux/Gemini), Live edit canvas
Tab 2: Assets: Uploader for image assets like subjects/characters/props or brand assets.
Tab 3: Templates: A gallery view of saved thumbnail layouts, also grouped into folders.

It will create Thumbnails in 4 ways: 

1. I paste a Thumbnail Strategy Note from NexLev MCP and the app uses Claude to generate appropriate prompts for the selected image generation model to generate a thumbnail image. 
2. I upload an asset image and the app uses the selected image generation model to generate a thumbnail image (either using my own prompt or Claude-generated prompt courtesy of NexLev MCP note)
3. I import a thumbnail image and click Recreate which makes the app  use Claude to generate appropriate prompts for the selected image generation model to generate a thumbnail image. 
4. Thumbnails created via the above 3 methods can be saved as Templates and used to generate new thumbnails.

Video script may or may not be uploaded/pasted and used by Claude when creating prompts.   Instructions (i.e. base prompt for Claude) may be used instead.

THE APP LOGIC & WORKFLOW:
AI Synthesis (The Strategy):
On generation, use puter.ai.chat() with the 'claude-sonnet-4.6' model.
Claude must analyze the Script and NexLev notes and output two distinct, highly detailed, high-CTR image prompts (A and B).

AI Render (The Image):
Call puter.ai.txt2img() using the user-selected Model and Aspect Ratio.

Image Generation:
If the user selects 'Flux 2 Pro', use puter.ai.txt2img() with the 'flux-1.1-pro' model.
If the user selects 'Nano Banana 2', use the 'gemini-3-flash-image' model.

The generated image must automatically load as the background image of the respective Fabric.js Canvas.

Live Manual Editing (The Polish):
When 'Add Text' is clicked, inject an editable Fabric.js Textbox object onto the active canvas. Apply the default YouTube branding style (High-contrast, bold font).
When 'Add Red Arrow' is clicked, inject a predefined arrow object.
Allow full manipulation (drag, rotate, resize, delete) of these added objects via mouse/touch.

Export (The Deliverable):
The final download button must take the Fabric.js Canvas (background + overlays), render it at full resolution, and save it as a PNG optimized for upload size (under 2MB for direct platform upload.)

Styling Notes: Keep the dashboard professional and clean, like a premium SaaS tool. Use rounded corners, distinct hover states, and clear loading animations. Give it a sleek 'Dark Mode' dashboard aesthetic with high-contrast buttons.
